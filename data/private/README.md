# Private league data

This directory is the local-only boundary for member names, contact details, payment status, and other registration information used by scripts and future agents.

`league-members.json` is generated from the source records workbook and ignored by Git. Never copy its contents into `apps/web/public`, tracked prompts, logs, fixtures, or generated website data.

`dues-2026.json` is generated by the local dues tracker. It stores the current-season roster, Venmo usernames, paid/unpaid state, payment timestamps, and commissioner notes. It is also ignored by Git.

`member-handles.json` maps each member's Sleeper username to their Apple handles, for `ug members handles load`. It is ignored by Git, and it is the only place the raw handles live: the loader hashes them on the way in, so `private.member_contacts` stores digests only and nothing ever prints a handle back out.

Use `league-members.example.json` when developing against the schema. It contains fake data only.
